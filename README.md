### 2.4 Historical data processing

Historical observations are taken from the course-provided `DATA2026.xlsx` workbook, using the `DATA` worksheet.

Daily stock and market returns are calculated from Total Return Indices (TRI):

\[
R_{i,t}=\frac{TRI_{i,t}}{TRI_{i,t-1}}-1.
\]

The daily risk-free rate is obtained from the Treasury Bill APR:

\[
r_{f,t}^{daily}=\frac{APR_t}{100\times360}.
\]

Daily excess returns are then calculated as:

\[
R_{i,t}^{excess}=R_{i,t}-r_{f,t}^{daily}.
\]

All expected returns, variances, and covariances used in portfolio analysis are expressed on an annual basis.

## 3. Methodology: Ten Tasks

### Task 1 — Expected Excess Returns

**Objective**

Estimate the annual expected excess return of each investable risky asset using the Single Index Model.

**Method**

The Single Index Model is:

\[
R_{i,t}-R_{f,t}
=
\alpha_i+\beta_i(R_{m,t}-R_{f,t})+\epsilon_{i,t}.
\]

The market beta is estimated by running an OLS regression of each asset's daily excess returns on the market's daily excess returns.

The expected annual excess return is then calculated using:

\[
E(R_i)-R_f
=
\alpha_i+\beta_i[E(R_m)-R_f].
\]

Here, the alpha is the analyst-provided forecast, while beta is estimated from historical observations.

**Implementation**

1. Load the historical TRI and Treasury Bill data.
2. Calculate daily returns and daily excess returns.
3. Estimate each stock's beta using OLS.
4. Combine estimated betas with analyst alpha forecasts.
5. Calculate annual expected excess returns.
6. Export the results to CSV.

**Output**

`task1_results.csv`

This output provides the expected excess return, estimated beta, analyst alpha, and regression statistics for each asset.

### Task 2 — Risk Decomposition

**Objective**

Estimate the total, systematic, and idiosyncratic variance of each risky asset.

**Method**

Under the Single Index Model:

\[
\sigma_i^2
=
\beta_i^2\sigma_m^2+\sigma_{\epsilon_i}^2.
\]

Systematic variance:

\[
\sigma_{i,systematic}^2
=
\beta_i^2\sigma_m^2.
\]

Idiosyncratic variance:

\[
\sigma_{i,idiosyncratic}^2
=
\sigma_{\epsilon_i}^2.
\]

Daily sample variances are annualized by multiplying by 250. Sample variance is calculated using `ddof=1`.

The model assumes that individual asset residuals are mutually uncorrelated.

**Implementation**

1. Reuse the daily excess returns and OLS regression framework from Task 1.
2. Calculate the annual market variance.
3. Estimate each stock's residual variance.
4. Calculate systematic and idiosyncratic variance.
5. Verify that total variance equals the sum of the two components.
6. Export the results.

**Output**

`task2_risk_decomposition.csv`

Variance values are expressed in annual decimal-return-squared units.

### Task 3 — Minimum Variance Frontier and GMVP

**Objective**

Construct the minimum variance frontier using 21 target-return portfolios and identify the Global Minimum Variance Portfolio (GMVP).

**Method**

The covariance matrix is constructed from the Single Index Model.

For different assets \(i\) and \(j\):

\[
Cov(R_i,R_j)=\beta_i\beta_j\sigma_m^2,
\quad i\neq j.
\]

The diagonal elements contain the total asset variances.

For a portfolio with weights \(w\):

\[
E(R_p)-R_f=w^T\mu,
\]

\[
\sigma_p^2=w^T\Sigma w.
\]

For each target expected excess return, solve:

\[
\min_w\quad w^T\Sigma w
\]

subject to:

\[
w^T\mu=\mu_{target},
\]

\[
\sum_iw_i=1,
\]

\[
w_i\geq0.
\]

The final constraint enforces the assignment's no-short-selling requirement.

**Implementation**

1. Construct the annual covariance matrix.
2. Define the portfolio variance objective function.
3. Generate 21 target expected excess returns.
4. Solve a constrained minimum variance problem for each target.
5. Calculate the resulting portfolio risks and returns.
6. Solve separately for the GMVP.
7. Plot the frontier in the expected excess return-risk plane.

**Outputs**

- `task3_covariance_matrix.csv`
- `task3_gmvp_weights.csv`
- `task3_frontier_21_portfolios.csv`
- `task3_frontier.png`

The GMVP minimizes portfolio variance, whereas the tangency portfolio in the following tasks maximizes the Sharpe ratio. These are different optimization objectives.

### Task 4 — Optimal Risky Portfolio: Maximization Procedure

**Objective**

Find the fully invested risky portfolio that maximizes the Sharpe ratio.

**Method**

The Sharpe ratio is:

\[
S_p=\frac{E(R_p)-R_f}{\sigma_p}.
\]

The optimization problem is:

\[
\max_w
\frac{w^T\mu}{\sqrt{w^T\Sigma w}}
\]

subject to:

\[
\sum_iw_i=1,\qquad w_i\geq0.
\]

Since `scipy.optimize.minimize` minimizes an objective function, the implementation minimizes the negative Sharpe ratio.

**Implementation**

1. Load the expected excess return vector and covariance matrix.
2. Define the negative Sharpe ratio as the objective function.
3. Set the fully invested and long-only constraints.
4. Use the SLSQP algorithm to solve the constrained nonlinear optimization problem.
5. Calculate the portfolio's expected excess return, annual risk, and Sharpe ratio.
6. Validate the weights and covariance matrix.
7. Export portfolio weights and summary statistics.

**Outputs**

- `task4_optimal_weights.csv`
- `task4_portfolio_summary.csv`

The resulting portfolio is the optimal risky portfolio under the specified constraints.

### Task 5 — Optimal Risky Portfolio: Closed-form Procedure

**Objective**

Calculate the optimal risky portfolio through a step-by-step closed-form approach and compare it with the numerical maximization result from Task 4.

**Method**

For an unconstrained tangency portfolio, the theoretical direction of the optimal weight vector is:

\[
w\propto\Sigma^{-1}\mu.
\]

The weights can be normalized to sum to one.

However, the standard unconstrained expression does not automatically satisfy the no-short-selling requirement. The long-only constraint must therefore be respected when determining the feasible solution.

The closed-form procedure is used to derive and verify the constrained portfolio, rather than treating an unconstrained solution with negative weights as an admissible final answer.

**Implementation**

1. Use the expected excess return vector and covariance matrix established in previous tasks.
2. Apply the step-by-step closed-form calculation.
3. Respect the long-only and fully invested constraints.
4. Normalize the resulting portfolio weights.
5. Calculate expected excess return, risk, and Sharpe ratio.
6. Compare the results with Task 4.

**Main result**

The closed-form procedure and numerical maximization produce the same optimal risky portfolio to numerical precision.

The resulting tangency portfolio has:

### Task 6 — Capital Allocation Line

**Objective**

Construct the Capital Allocation Line (CAL) using the tangency portfolio and the risk-free asset.

**Method**

The CAL describes the combinations of the risk-free asset and the tangency portfolio:

\[
E(R_c)-R_f
=
\frac{E(R_T)-R_f}{\sigma_T}\sigma_c.
\]

The slope is:

\[
\frac{E(R_T)-R_f}{\sigma_T}=S_T.
\]

Therefore, the slope of the CAL equals the Sharpe ratio of the tangency portfolio.

**Implementation**

1. Take the expected excess return and risk of the tangency portfolio from Task 5.
2. Calculate the CAL slope.
3. Generate complete-portfolio risk and expected excess return combinations.
4. Plot the CAL in the expected excess return-risk plane.

**Main result**

The CAL slope is approximately:

\[
S_T=0.3392.
\]

This line represents the best attainable risk-return combinations from mixing the risk-free asset with the optimal risky portfolio under the model assumptions.

### Task 7 — Optimal Complete Portfolio

**Objective**

Determine the optimal complete portfolio for an investor with a risk aversion parameter of \(A=6\).

**Method**

The optimal fraction invested in the tangency portfolio is:

\[
y^*=
\frac{E(R_T)-R_f}{A\sigma_T^2}.
\]

The remaining fraction is invested in the risk-free asset:

\[
1-y^*.
\]

The complete portfolio's expected excess return and risk are:

\[
E(R_C)-R_f=y^*[E(R_T)-R_f],
\]

\[
\sigma_C=y^*\sigma_T,
\]

for a non-negative allocation to the tangency portfolio.

The complete portfolio weights in individual risky assets are obtained by multiplying each tangency portfolio weight by \(y^*\).

**Implementation**

1. Load the tangency portfolio statistics.
2. Set the risk aversion parameter to 6.
3. Calculate the optimal allocation to the tangency portfolio.
4. Calculate the allocation to the risk-free asset.
5. Derive the final weights of all risky assets.
6. Calculate expected excess return and annual risk.
7. Export the complete portfolio composition and summary.

**Main result**

| Metric | Result |
|---|---:|
| Expected excess return | 1.9171% p.a. |
| Annual risk | 5.6526% |
| Sharpe ratio | 0.3392 |

The complete portfolio is investor-specific. It should not be confused with the tangency portfolio itself, which is the risky fund constructed in Tasks 4–5.

### Task 8 — Risk Aversion Threshold for Leverage

**Objective**

Determine the level of risk aversion below which an investor would want to leverage the tangency portfolio.

**Method**

From the optimal allocation formula:

\[
y^*=
\frac{E(R_T)-R_f}{A\sigma_T^2},
\]

leverage occurs when:

\[
y^*>1.
\]

Rearranging gives:

\[
A<
\frac{E(R_T)-R_f}{\sigma_T^2}.
\]

The threshold is therefore:

\[
A_{threshold}
=
\frac{E(R_T)-R_f}{\sigma_T^2}.
\]

**Implementation**

1. Use the tangency portfolio's expected excess return and variance.
2. Calculate the critical risk aversion parameter.
3. Interpret the investor's allocation in three cases:
   - \(A>A_{threshold}\): invest less than 100% in the tangency portfolio.
   - \(A=A_{threshold}\): invest 100% in the tangency portfolio.
   - \(A<A_{threshold}\): invest more than 100%, implying leverage.

**Main result**

\[
A_{threshold}\approx2.1386.
\]

Thus, under the model's borrowing assumptions, investors with a risk aversion parameter below approximately 2.1386 would want to leverage the tangency portfolio.

### Task 10 — Maximum Annual Management Fee

**Objective**

Estimate the maximum annual management fee that the active-passive fund can theoretically charge while remaining justified relative to a no-fee passive MSCI US investment.

**Method**

The active-passive fund's expected abnormal return is its portfolio alpha:

\[
\alpha_P=\sum_iw_i\alpha_i.
\]

The portfolio alpha is calculated using the tangency portfolio weights from Task 5 and the analyst alpha forecasts.

Under the assumption that the management fee is deducted from the fund's annual performance, the theoretical maximum fee is the amount that exhausts the fund's expected alpha:

\[
f_{max}=\alpha_P.
\]

This approach accounts for the fact that the active-passive portfolio may have a beta different from one. Simply subtracting the MSCI US expected return from the fund's expected return would not isolate the abnormal return generated by active stock selection.

**Implementation**

1. Load the tangency portfolio weights.
2. Match each stock's weight with its analyst alpha forecast.
3. Calculate the weighted alpha contribution of each asset.
4. Sum the contributions to obtain portfolio alpha.
5. Interpret the result as the theoretical maximum annual fee under the stated assumptions.

**Main result**

\[
\boxed{f_{max}=0.5674\%\text{ per annum}}
\]

This is a theoretical upper bound. It assumes that the analyst alpha forecasts are realized and excludes other costs such as transaction costs, taxes, and additional operating expenses.

## 7. Important Modeling Considerations

1. **Single Index Model:** Expected returns and covariance estimates are based on the Single Index Model, rather than mixing model-implied estimates with an unrelated empirical covariance matrix.

2. **Residual independence:** The covariance construction assumes that different assets' idiosyncratic residuals are uncorrelated.

3. **Long-only constraint:** Short selling is prohibited throughout the risky portfolio optimization.

4. **Risky versus complete portfolios:** The tangency portfolio contains risky assets only. The complete portfolio additionally combines the tangency portfolio with the risk-free asset.

5. **Annualization:** Stock returns use 250 trading days per year, while the Treasury Bill APR is converted to a daily rate using a 360-day convention.

6. **Management fee interpretation:** The 0.5674% fee is derived from the active-passive fund's weighted analyst alpha. It is a theoretical maximum under the stated assumptions, not a guaranteed commercially viable fee.

7. **Data availability:** Reproduction requires access to the original course-provided historical dataset. The repository's code and derived outputs do not replace that input.
